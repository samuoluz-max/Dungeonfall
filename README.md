# ⚔️ Dungeonfall

**Um jogo 2D de exploração de masmorras e combate cooperativo, desenvolvido com HTML, CSS e JavaScript.**

Dungeonfall é um jogo de fantasia medieval para navegador, com partidas cooperativas locais para **2 a 4 jogadores**, criaturas perigosas e chefes com diferentes padrões de ataque.

## 🎮 Funcionalidades

- 👥 Cooperativo local para 2 a 4 jogadores.
- 🏰 Três mapas com diferentes ambientações.
- 🐍 Chefes especiais: Naja, Golem e Dragão.
- 🎲 Combate com resultados aleatórios e acertos críticos.
- 🌐 Jogo desenvolvido para rodar no navegador.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🚀 Atualizações futuras

- 🌐 Multiplayer online para jogar com amigos pela internet.
- 🔑 Criação de salas com códigos de convite.
- ⚔️ Novas habilidades, animações e melhorias no combate.
- 🏰 Novos mapas, criaturas e chefes.
- ⚡ Otimizações de desempenho.

*As funcionalidades futuras ainda estão em planejamento ou desenvolvimento.*

## 🤖 Sobre o desenvolvimento

Dungeonfall foi desenvolvido durante um **hackathon escolar**, com autorização do professor para utilizar inteligência artificial como ferramenta de apoio à programação e ao desenvolvimento do jogo.

A IA auxiliou na implementação e no aprimoramento de funcionalidades durante o processo de criação.
